## 2. Purpose
This manual explains how to use the Knot platform from both the member and admin perspectives. It includes the main screens, common actions, and the places where screenshots should be inserted for submission.

## 3. User Roles
### 3.1 Member
A member can browse items, submit booking requests, contribute to campaigns, suggest new items, vote on suggestions, view notifications, and manage their own profile.

### 3.2 Admin
An admin can do everything a member can, plus approve bookings, moderate suggestions, manage users, review reports, manage settings, and perform other administrative tasks.

## 8. Troubleshooting
### 8.1 Login Problems
- Make sure you entered the correct username or email.
- Confirm your password is correct.
- Check whether your email has been verified.

### 8.2 Booking Problems
- Check that the item is available for the chosen dates.
- Confirm that the booking request includes all required fields.
- Ensure you do not have overdue bookings blocking new requests.

### 8.3 Payment Problems
- Confirm the phone number is correct.
- Wait a short time for callback or verification processing.
- Refresh the page or re-check payment status if the response is pending.

### 8.4 Admin Access Problems
- Confirm you are using an admin or approved steward account.
- Make sure the account is not blocked or unverified.
- Use the main admin dashboard rather than member pages.
